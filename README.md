# Foodie Madrid

Mapa personal de lugares guardados: filtros por tipo de lugar y comida, visitados, puntuación, mascotas y para trabajar.

Abre la app en https://flor-garcia.github.io/foodie-madrid/

Los datos que marcas se guardan en el navegador de cada dispositivo. Usa "Copia de seguridad" para pasarlos de uno a otro.
Mapa: © OpenStreetMap, CARTO; mapa de respaldo con datos de Overture Maps.
